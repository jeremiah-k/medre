## Unresolved or interrupted attempts

The archive also contains failed/interrupted campaigns, including native peer
receive timeouts, duplicate/echo assertions, and an operator harness
interruption. A final passing campaign does not retroactively convert those
attempts into passes. Their causes remain **unclassified** without correlated
per-attempt event IDs, process restarts, radio state and SQLite receipts.
Avoid declaring them either MEDRE defects or harmless RF noise based on a single
failure report. The separate interop experiment is still ongoing; its omitted
working directory must not be reconstructed or changed from this evidence.

## Evidence hygiene and next qualification

Before publishing a reproducible qualification record, capture the five
repository commit SHAs, exact scenario/config revision (sanitized), transport
and firmware versions, run IDs, and each sender/receiver pair's native receipt.
Keep the full machine-generated evidence **private**, preserving its provenance;
export only redacted summaries and reproduction steps. Run a control without
MEDRE for disputed native timeouts, then compare per-route delivery receipts,
native packet IDs and independent receiver observations. Do not silently rerun
only failed assertions until they pass without retaining the earlier evidence.

what a receipt means, see [Running MEDRE](../running-medre.md). This record
adds experimental context, not new normative behavior or API guarantees.
