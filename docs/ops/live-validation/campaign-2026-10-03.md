# Hardware Campaign: 2026-10-03

This record covers bounded functional iterations after a recent bench power
cycle, with the Meshtastic pair newly flashed. It records observations from
this campaign, not a guarantee for other firmware, presets, or networks.
Follow [short hardware iterations](short-iterations.md) to repeat the sequence.

## Defects and Harness Corrections

The local Synapse run exposed domainless room IDs from modern room versions.
MEDRE's auto-join validation incorrectly required a `:server` suffix. The
configuration regression failed before the fix; the focused room configuration
and routing suite passed 84 tests afterward. PR #249 accepts opaque domainless
IDs while still rejecting a bare `!`.

Encrypted Matrix assertions initially passed, but teardown left the provider's
SQLite crypto store open. A server-free real-SDK regression reproduced the
leak. PR #250 closes the store after provider shutdown, preserves its persistent
contents, and also covers partial startup and cancellation-resistant shutdown.
The focused suite passed 134 tests, and the Docker suite then exited cleanly.

PR #251 aligns live Synapse with the integration image and Renovate extraction,
separates LXMF relation assertions from optional power control, and retains
source acceptance and peer captures on convergence failures. Its power fixture
also restores after off-command failure or cancellation and requires fresh
post-restoration delivery. Sixteen focused harness tests passed; both standards
and adversarial behavior reviews had no outstanding findings.

## Failures and Limits Kept Visible

The first volume case durably admitted all 14 canonical events with exactly one
`sent` receipt per event. The Meshtastic peer observed only six of seven distinct
expected texts, below the unchanged 90% floor. The native control and MEDRE
repeat both observed every expected send. This did not establish the cause of
the initial loss; transient RF loss and receiver-window behavior remain possible.
No production retry or threshold change was made on that evidence.

The Matrix encrypted-attachment recipient case remains an expected failure
because recipient Megolm key exchange/decryption was not established in that
observation window. Ciphertext send shape is covered; it is not a claim of
encrypted attachment reception. Two older Matrix sync cases unexpectedly passed;
their markers remain visible pending a separate decision on their protocol gate.

The broad default suite in the all-extras hardware environment passed 17,547
tests but failed five. Three source-inspection failures disappeared when rerun
against a stable tree: the 68-test SDK parity suite passed. Two other cases
assumed optional SDKs were absent or incorrectly prohibited the adapter-list
command's intentional import probes. Their replacement tests simulate both
available and unavailable SDKs without changing the real guard module or
loading a user configuration; all 164 affected tests passed in the installed-SDK
environment. This correction is proposed in
[PR #252](https://github.com/jeremiah-k/medre/pull/252). The complete default
suite was not rerun locally after these corrections; the normal isolated CI
environments passed for the Matrix runtime fixes.

The serial recovery probe interrupted a PTY proxy while the actual RNode
remained powered. It verified SDK-owned host-link recovery and fresh RF
delivery, not a physical cable unplug, radio power loss, or reboot. Its private
probe and JSON retain before/after nonces, native hashes, and interface states.

A post-test MeshCore version query initially timed out because BlueZ still
marked one peer link connected. A targeted disconnect of that owned link
allowed both readbacks to complete. Test clients exiting is insufficient to
infer that every BLE central slot has been released; check ownership explicitly.

Verified physical power control was unavailable. The LXMF power case was
skipped; hub VBUS reports alone are insufficient for battery-backed devices.
External multi-hop reachability, propagation nodes, Matrix federation, and
long-duration endurance were outside this bench pass.
