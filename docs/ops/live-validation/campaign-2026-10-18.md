# Six-adapter native message campaign — 2026-10-18

The native campaign passed all 30 directed pairs across Matrix, Meshtastic,
MeshCore, LXMF, XMPP, and Chatmail. Six independently sent nonces each reached
the other five native peers. Final duplicate checks passed, every delivery had
matching core storage/outbox/receipt evidence, and all runtime and peer owners
stopped cleanly.

Matrix used a dedicated plaintext Synapse room, XMPP used a Prosody MUC, and
Chatmail used an accepted encrypted group between separate native core profiles.
The local Chatmail transport fixture was GreenMail SMTP/IMAP; this result does
not qualify deployment of the official Chatmail Docker server.

The physical bench included the RAK4631 and T1000-E Meshtastic pair, two paired
MeshCore T-Beams, and two Reticulum RNodes. Existing private radio settings were
retained. The MeshCore devices required release of idle Bluetooth connections
after pairing; their bonds were preserved. Both RNode interfaces were online at
916 MHz, 500 kHz bandwidth, SF8, coding rate 5, and 4 dBm transmit power.

Reticulum identity/path discovery completed after bridge startup and before the
first source turn. A separate SDK-only RNode pair check also passed. Omitting
that handshake produced a local queue handoff without the required native peer
receipt; the campaign rejected that incomplete result.

The final campaign used Python 3.14 and the adapter SDK/library versions
recorded in its private source-state and environment evidence. Adapter package
metadata remains the authority for dependency version constraints; this
historical campaign does not define current SDK pins. The private evidence
retains the harness/config digests, readiness diagnostics, per-peer JSONL/SDK
output, SQLite state, and the final full-coverage result. SDK-free pair/fanout and harness regressions passed with
60 tests; the native pytest entry point remained explicitly gated.

This bounded connectivity result covers text, group/room/channel addressing,
UTF-8 compatibility rendering, live provenance, native correlation, and cleanup.
It does not substitute for relation, attachment, restart, or sustained-load tiers.
