# Index historical native transport evidence and its limits

Add a machine-readable property/substrate index pointing to the existing
compatibility manifest and retained baseline report references. The index
makes reported independent SimpleX group peer evidence distinct from the
SDK-local queue boundary and from unqualified direct-contact recipient paths.
It also preserves the distinction between LXMF native-SDK-over-TCP evidence
in the frozen baseline and independently qualified physical RF paths elsewhere.
Private peer receipts are not embedded or reconstructed by this index.

Each provider's scope limits apply to the indexed reported evidence, rather than
claiming that a feature is universally unqualified. The reported LXMF baseline
uses TCP; physical RF evidence belongs to its separately scoped records.
