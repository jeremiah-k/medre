# Guided native connections, bounded route replacement and offline explanation

- Let independent providers optionally declare SDK-free native connection fields.
  The terminal form validates through production configuration models and pure
  preflight, creates private YAML exclusively and never starts hardware/SDKs.
  Refuse visible secret declarations and terminals without hidden input; redact
  captured credentials even when subsequent prompts fail.
- Support replacement of simple guided text routes in a **new output file**;
  reject missing IDs and advanced routes, including per-context attribution,
  rather than discarding policy or identity fields.
- Explain source matching and known allowlist restrictions through the same
  production compiler/router/policy evaluator; retain explicit limits about
  native capability and delivery evidence.
- Update the evidence limitations index with ownership and source-commit scope.
