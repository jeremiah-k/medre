# Qualify a uniform native presentation baseline

The baseline-v1 campaign fans out four independently authored text fixtures
through every selected adapter pair while keeping native owners alive. Chat
targets use a common full attribution template and constrained radio targets
use compact sender/source-instance attribution. Reports retain fixture coverage,
independent prefix/budget expectations and Matrix source metadata observations;
offline analysis rejects correct-looking text with wrong context or missing
fixtures. Production rendering defaults and multipart delivery are unchanged.
