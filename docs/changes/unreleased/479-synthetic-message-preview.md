# Pure, synthetic message preview

Add `medre config preview-message` to show actual registered renderer output
for every leg of a validated route without starting an adapter, persisting
work, or contacting a service. A fixed synthetic event supports bounded
text repetition and an explicit unresolved-reply fallback demonstration.
Only known rendered text and radio wire segments enter the versioned JSON
report; renderer failures expose closed reason codes instead of exception
text. No result implies a live routing decision, send authority, native
acceptance, or a recipient observation. Refresh native-setup guidance to
include the now-merged XMPP and LXMF pure forms.
