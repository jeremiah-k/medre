# Optional unreleased notes

Routine changes are recorded in their PR descriptions. Add a descriptively named
note here only for coordinated work, operator action or a migration explanation
that needs a durable document. Numbered filenames are not required.

At release time, incorporate useful notes into the versioned release summary and
archive or remove the individual note. The 0.1.0 numbered records are retained
under [their release archive](../releases/0.1.0/); they are historical context.
