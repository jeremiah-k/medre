# Explicit owned radio tail continuation

Add an explicit storage/service continuation boundary for a stable accepted
prefix followed by proven-unsent work. It requires a newer independently
reserved claim, exact latest predecessor, unchanged wire plan and consistent
history. Historical event, plan, adapter and channel provenance agrees with the
owned parent delivery identity before a continuation is bound. Original native handoff origins survive repeated transfers; old rows
and parent lifecycle stay unchanged. The service sends only the unsent suffix
through existing grants/pacing and aggregates the weakest complete local result.

Unknown/submitting handoffs, changed native payload semantics, replies, legacy
references without payload fingerprints, stale claims and conflicting history
remain held. Retained evidence that cannot be decoded fails permanently rather
than binding an attempt or reaching the native sender. Default dispatch and
automatic retry do not select continuation;
there is no new operator force-send command. Read-only typed checkpoint access
supports independent predecessor selection. No version, SQLite table shape or
schema-marker change, recipient-delivery promotion or physical RF claim.
