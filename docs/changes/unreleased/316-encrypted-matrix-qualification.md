# Encrypted Matrix native qualification

Add an optional Docker `encrypted` stage with independent native witnesses for
bidirectional encrypted text and files. Require encrypted wire events, verified
attachment plaintext, configured destination identities, correlated durable
receipts, stable device keys, and retained bytes across a runtime restart.

Retain private process captures and a standalone read-only analyzer. Decryption
and key-exchange failures fail qualification rather than producing an expected
failure. Document permissive peer-device trust and the separate OAuth and
cross-signing qualification boundaries.
