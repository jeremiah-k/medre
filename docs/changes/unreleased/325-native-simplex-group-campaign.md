# Qualify SimpleX groups with independent native peers

The native cross-adapter campaign includes SimpleX Chat through a separate
profile using the official SDK directly. Seven source turns exercise all 42
directed pairs and verify complete rendered text, native group/member identity,
core receipts, and duplicate suppression. Private support conversations cannot
qualify main-group delivery; peer SDK overrides are set before import. Local queue acceptance remains distinct
from independently observed group delivery.

Full plans require all seven transports. Existing six-transport fixtures remain
usable with an explicit --only selection and report partial coverage. The public
fixtures include separate SimpleX profiles and the MeshCore unverified sender
labels required by the provider's attribution contract.
