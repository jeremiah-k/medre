# Unreleased changes

Release summaries come from merged PR descriptions and GitHub's generated
release notes. Add a short entry here only when operator actions or a coherent
multi-PR explanation would otherwise be hard to find. See the
[change process](../dev/change-process.md).

- Use the committed Trunk launcher for the same quality gate locally and in CI.
  Development documentation distinguishes released, Git and editable sources.
- Released 0.1.0 development notes are archived; routine changes no longer
  require numbered fragments.
